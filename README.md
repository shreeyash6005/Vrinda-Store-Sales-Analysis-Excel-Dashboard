# Vrinda-Store-Sales-Analysis-Excel-Dashboard
Project Objective
The objective of this project was to analyze Vrinda Store's sales data and generate meaningful business insights using Microsoft Excel. The analysis helps identify sales trends, customer behavior, top-performing states, sales channels, and order performance to support data-driven business decisions.

Project Overview
This project was developed entirely in Microsoft Excel using data cleaning, data analysis, Pivot Tables, Pivot Charts, and dashboard creation techniques. The goal was to transform raw sales data into an interactive and visually appealing business dashboard.

Project Workflow
1. Data Collection & Understanding
Imported the sales dataset into Excel.
Reviewed customer, sales, and order-related information.
Explored the dataset to understand business requirements.
2. Data Cleaning
Removed duplicate records.
Checked for missing and inconsistent values.
Corrected data formatting and data types.
Prepared the dataset for analysis.
3. Data Analysis
Analyzed monthly sales performance.
Studied customer purchasing behavior by age and gender.
Identified top-performing states.
Examined sales contribution by different channels.
Evaluated order status and fulfillment trends.
4. Dashboard Development
Created Pivot Tables for analysis.
Developed Pivot Charts for visualization.
Built an interactive Excel Dashboard.
Added slicers for dynamic filtering and reporting.
Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Key Insights
Women customers contributed a higher share of sales.
Adult customers generated the highest revenue.
Maharashtra, Karnataka, and Uttar Pradesh were among the top-performing states.
Amazon, Flipkart, and Myntra contributed significantly to total sales.
Most orders were successfully delivered with a low cancellation rate.
Outcome
The dashboard provides a clear overview of sales performance and customer behavior, helping businesses identify growth opportunities and make informed decisions based on data.
